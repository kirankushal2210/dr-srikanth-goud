#### 2. Component Implementation: `src/components/sections/MediaGallery.tsx`

Build this component with:
1. Section Header:
   - Eyebrow: `📸 ARCHIVAL PHOTOGRAPHS • THE LEADERSHIP RECORD` in TRS Yellow.
   - H2 Headline: "Photographic Archive & Public Life"
   - Telugu Subtitle: "ప్రజా జీవితంలో మైలురాళ్ళు — అరుదైన చిత్రమాలిక"
2. Filter Tabs:
   - Buttons:
     * All Moments (`all`)
     * Leadership & Dignitaries (`leadership`)
     * Frontline Agitations (`agitations`)
     * Cadre & Assembly Meets (`cadre`)
     * Social Welfare & COVID Relief (`welfare`)
     * Devotional & Cultural (`devotional`)
   - Styled with active TRS Yellow fills (`bg-trs-yellow text-slate-950 font-bold`) and inactive dark green buttons (`bg-trs-green-surface text-slate-300 border border-trs-green-border`).
3. Responsive Grid (3 Columns on Desktop, 2 on Tablet, 1 on Mobile):
   - Card displays:
     * Photo container with hover zoom (`group-hover:scale-105 transition-transform duration-300`).
     * Fallback placeholder styling if image fails to load.
     * Top-left pill: Page reference badge (`PDF P. 09`, `PDF P. 23`, etc.).
     * Top-right pill: Category Tag (`Youth Rights`, `Cadre Leadership`, etc.) in TRS Azure Blue.
     * Bottom overlay text: English Title, Telugu Translation, and Location with MapPin icon.
     * Click card action: Opens Lightbox.
4. Lightbox Modal:
   - Fullscreen backdrop blur (`backdrop-blur-md bg-black/85`).
   - Image rendered high-resolution in center.
   - Information card beneath/beside:
     * Title (EN + TE).
     * Location.
     * Full paragraph narrative description (EN + TE).
     * Close button (`X` icon and `Escape` key trigger).
